✨ Key Features

💻 Multi‑platform — Windows, macOS, Linux. Supports CUDA, CPU, Apple CoreML.
📁 Directory Management — Add/remove folders, auto‑detect new/modified files.
🔍 Dual‑path Search — Semantic search (e.g., "a cup of coffee") + lightning‑fast SQL tag search.
🏷️ Custom AI Tags — Define any labels (Chinese/English) and tag on demand with one click.
🧠 Flexible AI Engine — Auto, GPU, CPU, or Apple CoreML (macOS Neural Engine). All local.
🔒 Model Lockdown — SHA256 checksum, resumable downloads, auto‑repair, fallback mirrors.

🚀 Quick Start (Development)

# Dependencies: Rust 1.70+, tauri-cli 2.x (macOS: Xcode CLT, Windows: VS Build Tools)
cargo tauri dev # development mode
cargo tauri build # production build

On first launch, the AI model (~412 MB) is downloaded automatically.
Windows: copy vendor/onnxruntime/win-x64/onnxruntime.dll to the executable directory.
macOS: requires a universal2 onnxruntime.dylib (with CoreML EP). See BUILD.md for details.

📂 Data Locations

Database / thumbnails
Windows: %APPDATA%\com.tiol.desktop
macOS: ~/Library/Application Support/com.tiol.desktop
AI models
Windows: %LOCALAPPDATA%\com.tiol.desktop\models
macOS: ~/Library/Caches/com.tiol.desktop/models
